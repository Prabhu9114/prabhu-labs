The Problem

Sending the same run of posts to several Telegram channels by hand is slow and easy to get out of order. Doing it in bulk also runs into Telegram’s rate limits.

The Solution

OmniPost Cloud copies posts from one source channel to each destination channel in sequential batches. Every destination keeps its own pointer, so channels don’t repeat or skip posts, and sending is paced to stay clear of flood waits. When the source runs out, it loops back to the start.

Architecture

How It Works

  1. 01

    Batch Dispatch

    Sends each destination its own block of posts, paced to avoid flood waits.

  2. 02

    Webhook Channel Discovery

    Detects when the bot is made admin, so no manual Chat IDs are needed.

  3. 03

    Workers KV State

    Keeps tenant pointers and access flags at the edge, looping back to the start when the source ends.
