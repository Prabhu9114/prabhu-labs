TeleGrowth Engine

Approve channel join requests instantly and keep a record of who you can message.

Open @Quick_Join_BotContact

The Problem

Channels with join requests turned on need every request approved by hand, and approving alone doesn’t tell you which new members you can actually message afterwards.

The Solution

TeleGrowth Engine approves join requests instantly through an edge webhook, then sends a short interactive verification. Completing it opens a two-way DM and records can_dm = 1, so you know who can be reached. All subscriber records live in a central D1 SQL ledger.

How It Works

  1. 01

    Fast Approval

    Handles join requests through Cloudflare Workers webhooks.

  2. 02

    Verification Hook

    An interactive challenge opens a two-way DM and sets the can_dm flag in the database.

  3. 03

    Central D1 SQL Ledger

    Stores unified subscriber records in SQLite at the edge.
